# Algorithm Tasks Repository

This repository contains algorithmic implementations, theoretical analysis, and empirical benchmarks.

## Tasks Directory

| Task | Topic | Key Files | Description |
| :--- | :--- | :--- | :--- |
| **[Task 1](./task-1)** | Empirical Analysis of Insertion Sort | `insertion_sort.py`, `experiment.py`, `REPORT.md` | $\mathcal{O}(n^2)$ vs $\mathcal{O}(n \log n)$ empirical performance, comparison & shift counting. |
| **[Task 2](./task-2)** | Sorting Benchmark Lab | `benchmark.py`, `benchmark_plot.png` | Comprehensive benchmark across Insertion Sort, Merge Sort, Quick Sort, and Timsort. |
| **[Task 3](./task-3)** | OS Task Scheduler Simulation | `task_scheduler.py`, `README.md` | CPU priority scheduling simulation backed by a binary Max-Heap. |
| **[Task 4](./task-4)** | Island Counter | `island_counter.py`, `README.md` | Connected component counting in 2D binary grids using DFS and BFS flood fill with NumPy. |
